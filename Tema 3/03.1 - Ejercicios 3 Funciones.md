## Ejercicio 3.1 · Comprobar números primos

```kotlin
fun isPrime(n: Int): Boolean {
    if (n <= 1) return false
    if (n == 2) return true
    if (n % 2 == 0) return false
    var divisor = 3
    while (divisor * divisor <= n) {
        if (n % divisor == 0) return false
        divisor += 2
    }
    return true
}
```

## Esquema resumen de conceptos clave

| Concepto | Sintaxis | Idea clave |
| --- | --- | --- |
| Retorno anticipado | `return` | Termina función en cuanto se cumple condición |
| `Unit` | retorno omitido | Función ejecuta acción sin resultado útil |
| `Nothing` | `throw` | Rama que nunca retorna normalmente |
| Sobrecarga | mismo nombre, firmas distintas | Selección por tipos de argumentos |
| Default | `p: T = valor` | Permite omitir argumento |
| Named argument | `p = valor` | Saltar parámetro opcional con claridad |
| `vararg` | `vararg xs: T` | Acepta cantidad variable |
| Spread | `*array` | Expande array a argumentos |
| `infix` | `obj verbo arg` | Método de un parámetro con sintaxis infija |
