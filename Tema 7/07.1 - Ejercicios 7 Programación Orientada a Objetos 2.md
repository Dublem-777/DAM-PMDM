## Ejercicio 7.1 · Herencia

```kotlin
open class Animal(val nombre: String) {
    open fun sonido() = "..."
}
class Perro(nombre: String) : Animal(nombre) {
    override fun sonido() = "Guau"
}
```

## Ejercicio 7.2 · Polimorfismo

```kotlin
val animales: List<Animal> = listOf(Animal("animal"), Perro("Toby"))
animales.forEach { println(it.sonido()) }
```

## Ejercicio 7.3 · Clase abstracta

```kotlin
abstract class Figura {
    abstract fun area(): Double
}
class Cuadrado(val lado: Double) : Figura() {
    override fun area() = lado * lado
}
```

## Ejercicio 7.4 · Interfaces

```kotlin
interface Imprimible { fun imprimir() }
class Informe : Imprimible {
    override fun imprimir() = println("Informe")
}
```

## Ejercicio 7.5 · Comprobación de tipo y smart cast

```kotlin
fun describir(valor: Any) = when (valor) {
    is String -> "Texto de ${valor.length} caracteres"
    is Int -> "Entero: $valor"
    else -> "Otro tipo"
}
```

## Ejercicio 7.6 · Conversión segura

```kotlin
val animal: Animal = Perro("Toby")
val perro: Perro? = animal as? Perro
```

## Ejercicio 7.7 · Clases selladas

```kotlin
sealed interface Resultado
data class Correcto(val valor: String) : Resultado
data class Fallido(val motivo: String) : Resultado

fun mostrar(resultado: Resultado) = when (resultado) {
    is Correcto -> resultado.valor
    is Fallido -> resultado.motivo
}
```

## Ejercicio 7.8 · Delegación por interfaz

```kotlin
interface Logger { fun log(mensaje: String) }
class ConsolaLogger : Logger { override fun log(mensaje: String) = println(mensaje) }
class Servicio(logger: Logger) : Logger by logger
```

## Ejercicio 7.9 · Clase interna

```kotlin
class Externa(val dato: String) {
    inner class Interna { fun mostrar() = dato }
}
```
