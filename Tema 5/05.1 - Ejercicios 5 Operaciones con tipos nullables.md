# Ejercicios 5: Operaciones con tipos nullables

> [!info] Origen
> [[DAM/Programacion_Multimedia_y_Dispositivos_Moviles/Indice|PMDM]] · Teoría: [[05 - Operaciones con tipos nullables]]

## Ejercicio 5.1 · Longitud segura

```kotlin
fun longitud(texto: String?): Int = texto?.length ?: 0
```

## Ejercicio 5.2 · Valor alternativo

```kotlin
fun nombreVisible(nombre: String?): String = nombre ?: "Invitado"
```

## Ejercicio 5.3 · Llamadas encadenadas

```kotlin
data class Direccion(val ciudad: String?)
data class Persona(val direccion: Direccion?)

fun ciudad(persona: Persona?): String? = persona?.direccion?.ciudad
```

## Ejercicio 5.4 · Comprobación explícita

```kotlin
fun imprimirLongitud(texto: String?) {
    if (texto != null) println(texto.length)
}
```

## Ejercicio 5.5 · Conversión segura

```kotlin
val numero: Int? = "123a".toIntOrNull()
```

## Ejercicio 5.6 · Conversión de tipo segura

```kotlin
val texto: String? = valor as? String
```

## Ejercicio 5.7 · Aserción no nula

```kotlin
val nombre: String? = "Kotlin"
val longitud: Int = nombre!!.length
```

> [!warning] Uso de `!!`
> El ejemplo funciona solo si valor no es `null`; si lo es, lanza `NullPointerException`. Preferir `?.` o `?:`.

## Esquema resumen de conceptos clave

| Operador | Resultado |
| --- | --- |
| `?.` | Llamada segura, resultado nullable |
| `?:` | Alternativa cuando valor es null |
| `!!` | Fuerza no nulidad y puede lanzar NPE |
| `as?` | Cast seguro, null si falla |
