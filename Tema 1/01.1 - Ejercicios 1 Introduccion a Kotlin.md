## Ejercicio 1.1 · Ordenar tres números enteros por consola

> [!question] Enunciado
> Solicita por consola tres números enteros y muéstralos en orden.

### Solución

```kotlin
fun main() {
    print("Escribe tres números separados por espacios: ")
    val numeros = readln().split(' ').map { it.toInt() }.sorted()
    println(numeros.joinToString(" - "))
}
```

### Conceptos clave

- `readln()` lee una línea como `String`.
- `split(' ')` separa los valores; `toInt()` convierte cada uno.
- `sorted()` devuelve números en orden ascendente.
- `joinToString()` forma una cadena con separador.

## Esquema resumen de conceptos clave

| Concepto | Sintaxis | Uso |
| --- | --- | --- |
| Entrada | `readln()` | Leer texto de consola |
| Conversión | `toInt()` | Convertir texto a entero |
| Ordenación | `sorted()` | Orden ascendente |
| Formato | `joinToString(" - ")` | Mostrar valores separados |
