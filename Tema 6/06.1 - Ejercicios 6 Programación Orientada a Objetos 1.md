## Ejercicio 6.1 · Clase Persona

```kotlin
class Persona(val nombre: String, var edad: Int) {
    fun cumplirAnios() { edad++ }
}
```

## Ejercicio 6.2 · Instancias

```kotlin
val ana = Persona("Ana", 20)
val luis = Persona("Luis", 25)
```

## Ejercicio 6.3 · Método de instancia

```kotlin
fun Persona.presentarse() = println("Soy $nombre y tengo $edad años")
```

## Ejercicio 6.4 · Propiedad calculada

```kotlin
class Rectangulo(val ancho: Double, val alto: Double) {
    val area: Double get() = ancho * alto
}
```

## Ejercicio 6.5 · Constructor secundario

```kotlin
class Punto(val x: Int, val y: Int) {

```

## Ejercicio 6.6 · Encapsulación

```kotlin
class Contador {
    var valor: Int = 0
        private set
    fun incrementar() { valor++ }
}
```

## Ejercicio 6.7 · Data class

```kotlin
data class Producto(val nombre: String, val precio: Double)
```

## Ejercicio 6.8 · Copia de datos


## Ejercicio 6.10 · Objeto singleton

## Ejercicio 6.11 · Companion object

```kotlin
class Usuario(val nombre: String) {

```

## Ejercicio 6.12 · Visibilidad

```kotlin
class Cuenta(private var saldo: Double) {
    fun ingresar(cantidad: Double) { if (cantidad > 0) saldo += cantidad }
}
```

## Ejercicio 6.13 · Inicialización tardía

```kotlin
class Servicio {
    lateinit var endpoint: String
}
```

`lateinit` solo aplica a propiedades `var` no nullable de tipo referencial, no a primitivos.

## Ejercicio 6.14 · Delegación de propiedad

```kotlin
import kotlin.properties.Delegates

class UsuarioMutable {
    var nombre: String by Delegates.observable("") { _, anterior, nuevo ->
        println("$anterior → $nuevo")
    }
}
```
